# LibrarySys

Sistem Informasi Perpustakaan yang membantu mengelola buku, anggota, peminjaman, dan berbagai kebutuhan administrasi perpustakaan melalui 30+ fitur CRUD, dilengkapi login & register, database SQLite, profil pengguna, dashboard, serta dukungan offline. Aplikasi dibangun menggunakan Electron dan dapat dijalankan sebagai aplikasi desktop Windows (.exe), Mac (.app/.dmg), maupun Linux.
